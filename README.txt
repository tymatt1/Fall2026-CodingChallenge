SuperImage

Author: Matthew Tybur
Vanderbilt Email: matthew.l.tybur@vanderbilt.edu

Description:
SuperImage is a full-stack web application built for discovering images,
organizing them into collections, editing or removing saved photos, and 
sharing them through unique links.

Specifications:
- React and Vite for the frontend
- Node.js, Express, and Cors for the backend server
- SQLite v3 for persistant data storage
- Pixabay API for image search

Setup:
- Install Node.js
- Open a terminal window in the backend folder
- Copy backend/.env.example to backend/.env
- Replace the Pixabay API key placeholder in .env with your own key
- Open another terminal window in the frontend folder, and run: npm install

Run Instructions:
- In the backend terminal, run: npm run dev
- In the frontend terminal, run: npm run dev
- visit http://localhost:5173 in a web browser
- The backend runs on port 3001. Keep both the front-end and back-end terminal windows open while running

Reflection:
- Building this web application was an exciting and constructive project for me. This  
was my first full stack application, and learning Vite, React, Express, and SQL was 
challenging but fun. One concept I enjoyed learning was React's map() function, a unqiue way
to modify an array which I used for operating on the collections. Furthermore, 
learning about REST API calls within Express and their usage by frontend functions
was interesting. Finally, a difficult challenge I faced was learning SQL and integrating a 
permanent database into my Express/React temp storage system. Overall, this project was both
fun and insightful.
